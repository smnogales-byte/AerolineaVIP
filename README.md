# Sistema Web Monolitico - Aerolinea VIP

Sistema web para compra, reserva y administracion de pasajes de una aerolinea VIP.
- Flota: 3 Embraer Phenom 300E (capacidad estricta de 7 asientos por vuelo).
- Arquitectura: ASP.NET Framework 4.8.1 (MVC), Razor, Bootstrap, jQuery.
- Persistencia: SQL Server e Identity Framework.
